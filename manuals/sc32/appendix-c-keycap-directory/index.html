    C.1.1 Tactile Snap-Dome Mechanics & Debouncing Algorithm

    • Actuation Force: \(400\,\text{g}\) tactile stainless steel snap domes providing an unambiguous mechanical snap threshold.
    • Key Travel: \(0.35\,\text{mm}\) short-stroke actuation ensuring zero lost motion.
    • Firmware Debounce Architecture: Eager actuation on leading falling edge (\(0\,\text{ms}\) latency) followed by a \(20\,\text{ms}\) lockout window. This eliminates double-strike bounce artifacts even under aggressive 50-problem contest bursts.

    C.2 Electrical Matrix & Keypad Scanning Bus

    The switch matrix is wired as an \(8 \times 6\) crossbar scanned by the dual-core 32-bit microcontroller:

    • Row Lines (Strobed Outputs): GPIO pins [6, 7, 8, 9, 10, 14, 18, 19]. Strobed low sequentially in round-robin sequence at \(1\,\text{kHz}\) scanning frequency.
    • Column Lines (Sensed Inputs): GPIO pins [11, 12, 13, 15, 16, 17]. Pulled high internally by \(50\,\text{k}\Omega\) resistors; active-low detection.
    • Hardware Sleep Wake Interrupt: Row 7, Column 0 ([C]/ON switch) is routed to an asynchronous edge-triggered interrupt. When the calculator is in deep \(11.8\,\mu\text{A}\) sleep, depressing this key immediately wakes the system clock within \(5\,\text{ms}\).

    C.4 Authoritative HP32SII Deviations Master Index

    The SC-32 intentionally deviates from the 1988 vintage HP-32SII in exact alignment with the project button rubric:

    1. [↱] + +/- = |x| (Absolute Value):
    2. HP32SII Original: ( (open parenthesis for algebraic equation editor).
    3. SC-32 Rationale: Parentheses are redundant in direct RPN mode; direct absolute value is far more useful in applied engineering.
    4. [↱] + E = ÷R (Integer Division & Remainder):
    5. HP32SII Original: ) (close parenthesis for algebraic equation editor).
    6. SC-32 Rationale: Returns integer quotient in \(Y\) and remainder in \(X\) in a single keystroke.
    7. [↱] + <- = Unassigned:
    8. HP32SII Original: = (equals for algebraic equation editor).
    9. SC-32 Rationale: Equality comparison belongs in the x?y and x?0 menus; left unassigned.
    10. [↰] + 0 = REGS (Register Viewer):
    11. HP32SII Original: INPUT (program input prompt).
    12. SC-32 Rationale: Programming prompts are replaced by dynamic equation parameters; REGS allows instant inspection of all variables.
    13. Key Row 7, Col 3 (Multi-Action Key):
    14. HP32SII Original: R/S (Run/Stop program execution).
    15. SC-32 Assignment: Primary: x∥y, Left Shift [↰]: TVM, Right Shift [↱]: PLOT, Alpha: (i).
    16. SC-32 Rationale: Traditional line programming is replaced by RPN step equations, numerical quadrature, root finding, and financial solvers.
    17. [↰] + + = LBL:
    18. Restored equation safety key ensuring equations retain explicit labels.
    19. [↱] + XEQ = POLY:
    20. Cubic polynomial solver workspace (A B C D EXEC CLR on LFU softkeys).
    21. Top 6 LFU Dynamic Softkeys:
    22. Context-aware softkey strip permanently positioned above the primary math rows.
