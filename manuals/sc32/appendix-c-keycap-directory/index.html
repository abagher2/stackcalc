    Appendix C: Physical Keycap & Softkey Menu Directory

    The StackCalc SC-32 organizes its 43-key tactile matrix (Figure C.1) into three ergonomic zones paired with a three-layer shift grammar that groups functions by mathematical association without deeply nested menu trees.

    C.1 Three-Zone Keypad Architecture & Shift Grammar

    Beneath the top row of six dynamic softkeys ([LFU0]–[LFU5]), each of the 37 main physical keys carries three operational meanings plus an automatic alpha character (A–Z, i, (i)):

    • Primary Legend (White Center Label — 1 Tap): Executes the primary operation for that key position: core transcendentals ([√x], [eˣ], [LN], [yˣ], [1/x], [SIN], [COS], [TAN]), statistical accumulation ([Σ+]), stack and memory control ([STO], [RCL], [R↓], [ENTER], [x⇄y]), and postfix arithmetic ([÷], [×], [-], [+], [x∥y]).
    • Left Shift ([↰] — Mathematical Inverse or SI Companion): Accesses the mathematical inverse printed over the upper-left corner ([√x] \(\leftrightarrow\) [↰] [x²], [eˣ] \(\leftrightarrow\) [↰] [10ˣ], [LN] \(\leftrightarrow\) [↰] [LOG], [yˣ] \(\leftrightarrow\) [↰] [ˣ√y], [1/x] \(\leftrightarrow\) [↰] [x!], [Σ+] \(\leftrightarrow\) [↰] [Σ-], [SIN] \(\leftrightarrow\) [↰] [ASIN], [COS] \(\leftrightarrow\) [↰] [ACOS], [TAN] \(\leftrightarrow\) [↰] [ATAN], [ENTER] \(\leftrightarrow\) [↰] [LASTX]), complex/hyperbolic prefixes ([↰] [CMPLX], [↰] [HYP]), system menus (MODES, DISP, CLEAR, BASE, REGS, TVM), and metric/polar conversions ([↰] [▸km], [↰] [▸kg], [↰] [▸°C], [↰] [▸cm], [↰] [▸l], [↰] [▸θ,r], [↰] [▸HR], [↰] [▸DEG]).
    • Right Shift ([↱] — Analytical Workspaces, Solvers & Softkey Menus): Opens domain softkey menus (PARTS, PROB, L.R., x̄,ȳ, s,σ, SUMS, FLAGS, x?0), numerical solvers ([↱] [POLY], [↱] [SOLVE], [↱] [∫], EQN), specialized operators (π, [↱] [%], [↱] [%CHG], [ABS], [↱] [÷R], [↱] [SHOW]), and imperial/rectangular conversions ([↱] [▸mi], [↱] [▸lb], [↱] [▸°F], [↱] [▸in], [↱] [▸gal], [↱] [▸y,x], [↱] [▸HMS], [↱] [▸RAD]).
    • Alpha Labels (A–Z, i, (i)): Activate whenever a command prompts for a register or label ([STO], [RCL], [XEQ], FN=, LBL, [↱] [SOLVE], [↱] [∫]). The (i) label on [x∥y] dereferences pointer i across all 89 memory slots (1–26 = A–Z, 27 = i, 28–33 = statistical sums, 34–39 = POLY roots, 40–89 = DATA0–DATA49).
    Zone Rows & Pitch Architectural Layout
    Upper Function Zone Rows 0–2 (6 Cols) Row 0: [LFU0]–[LFU5] dynamic softkeys. Row 1: [√x], [eˣ], [LN], [yˣ], [1/x], [Σ+]. Row 2: [STO], [RCL], [R↓], [SIN], [COS], [TAN].
    Transition Zone Row 3 (5 Keys / 6 Cols) Double-wide [ENTER] bar (Cols 0–1), [x⇄y] (Col 2), [+/-] (Col 3), [E] (Col 4), and dual-mode [<-] / CLx (Col 5).
    Lower Arithmetic Zone Rows 4–7 (5 Cols) Col 0: [XEQ], [↰], [↱], [C]. Cols 1–3: 0–9, ., [x∥y]. Col 4: [÷], [×], [-], [+].

    C.2 Physical Matrix Coordinate Grids by Zone

    Row 0 ([LFU0]–[LFU5]) is a context-aware LFU (Least Frequently Used) dynamic softkey strip: in normal state, it surfaces the six functions tracked by the LFU algorithm, and whenever a menu or workspace (such as PARTS, PROB, L.R., BASE, MODES, DISP, FLAGS, TVM, or POLY) opens, it remaps to that menu's softkey labels along the bottom row of the LCD. Row 1 groups power, exponential, logarithmic, reciprocal, and statistical accumulation operators along a single row, while Row 2 pairs register management ([STO], [RCL]) and circular stack rotation ([R↓]) with planar trigonometry ([SIN], [COS], [TAN]):

    Upper Zone Row Col 0 Col 1 Col 2 Col 3 Col 4 Col 5
    Row 0 [LFU0] [LFU1] [LFU2] [LFU3] [LFU4] [LFU5]
    Row 1 [√x] [eˣ] [LN] [yˣ] [1/x] [Σ+]
    Row 2 [STO] [RCL] [R↓] [SIN] [COS] [TAN]

    Across Row 3, five physical keys bridge the upper 6-column scientific deck and the lower 5-column numeric pad. Anchoring Columns 0–1 is the double-wide [ENTER] bar ([↰] [LASTX] on [↰], [↱] [SHOW] on [↱]), flanked by [x⇄y], [+/-], [E], and dual-mode [<-] (character backspace during EDIT; CLx on a finalized register):

    Transition Row Col 0 & 1 (Double-Wide) Col 2 Col 3 Col 4 Col 5
    Row 3 [ENTER] [x⇄y] [+/-] [E] [<-]

    Rows 4–7 widen into a 5-column numeric and postfix arithmetic grid. Column 0 houses [XEQ] (FN= / POLY), latching shifts [↰] and [↱], and [C] (? / OFF). Column 4 houses [÷], [×], [-], and [+]. Across the central 0–9, ., and [x∥y] keys in Columns 1–3, shifted legends provide root finding ([↱] [SOLVE] on [7]), Romberg integration ([↱] [∫] on [8]), 2D vector and angular conversions ([4], [5], [6]), SI \(\leftrightarrow\) Imperial unit conversions ([9], [1], [2], [3], [-]), register inspection ([0]), rational fraction control ([.]), and the 5-variable TVM financial workspace ([x∥y]):

    Lower Zone Row Col 0 Col 1 Col 2 Col 3 Col 4
    Row 4 [XEQ] [7] [8] [9] [÷]
    Row 5 [↰] (Left Shift) [4] [5] [6] [×]
    Row 6 [↱] (Right Shift) [1] [2] [3] [-]
    Row 7 [C] (ON) [0] [.] [x∥y] [+]

    C.4 Dynamic LFU Softkey Menus & Analytical Workspaces Directory

    The six top keys ([LFU0] through [LFU5]) dynamically remap to on-screen menu labels along the bottom pixel row of the transflective LCD whenever a modal menu or analytical workspace is opened, executing the corresponding softkey action without obscuring the four visible stack registers (\(T, Z, Y, X\)). In normal calculation mode (ALL/FIX/SCI/ENG without an active modal submenu), the six softkey slots display the six most frequently invoked functions, retained by a Least-Frequently-Used (LFU) cache-eviction policy:

    Menu / Workspace Access Keystroke Top-Row Softkeys (LFU0 – LFU5) Default & Execution Behavior
    DISP [↰] + [E] FIX n, SCI n, ENG n, ALL Default ALL; tapping FIX, SCI, or ENG prompts for digit 0–9 (• marks active format).
    MODES [↰] + [+/-] DEG, RAD, GRAD, ., , Default DEG and radix .; active angular unit and radix mark carry a bullet (•).
    BASE [↰] + [×] HEX, DEC, OCT, BIN Default DEC; re-renders integers in \([-2^{35}, 2^{35}-1]\) (64-bit two's complement for negatives; HEX maps Row 1 keys to A–F).
    CONST Companion / Menu π, e, h, c, G, Na, R, k Pushes fundamental physical/mathematical constants (\(\pi, e, h, c, G, N_A, R, k_B\)) to \(X\) with stack lift.
    CLEAR [↰] + [<-] CLEQN, CLVARS, CLALL, CLSTAT, CLREGS, CLSTK Resets the selected subsystem to 0 (CLSTAT aliases [CLΣ]) without disturbing other workspaces.
    MEM [↰] + [x⇄y] VARS, EQN, REGS Displays available memory and catalogs allocated variable, equation, and register blocks.
    FLAGS [↱] + [×] STACK ▸, MODE ▸, UI ▸, EXAM, SF, CF Displays 10-flag status grid (0:F0–9:d/c) toggled by digits 0–9 (or submenus in companion app).
    STACK FLAGS \(\to\) STACK 2-LVL, 4-LVL, 8-LVL, INF, VIEW Default 4-LVL (\(T, Z, Y, X\) with \(T\)-replication) and 4-LN four-line view (VIEW toggles 1-LN).
    PARTS [↱] + [√x] IP, FP, ABS, SGN, GCD, LCM Monadic IP, FP, ABS, SGN act on \(X\); dyadic GCD and LCM reduce integers across \((Y, X)\).
    PROB [↱] + [eˣ] Cn,r, Pn,r, n!, RAND, SD Cn,r and Pn,r consume \((Y = n,\; X = r)\); RAND pushes \(U[0,1)\) with stack lift; SD seeds generator from \(X\) and drops stack.
    SUMS [↱] + [Σ+] Σx, Σy, Σx², Σy², Σxy, n Recalls the six sufficient statistics (R28 = n, R29 = Σx, R30 = Σy, R31 = Σx², R32 = Σy², R33 = Σxy) to \(X\) observing stack lift (Σ+ disables lift so first query overwrites \(n\) in \(X\) and enables lift).
    x̄,ȳ [↱] + [yˣ] x̄, ȳ, x̄w Each softkey places its mean (\(\bar{x}\), \(\bar{y}\), or \(\bar{x}_w = \Sigma xy / \Sigma y\)) into \(X\) observing stack lift and enables stack lift.
    s,σ [↱] + [1/x] sx, sy, σx, σy Each softkey places its standard deviation (\(s_x\), \(s_y\) with \(n - 1\), or \(\sigma_x\), \(\sigma_y\) with \(n\)) into \(X\) observing stack lift and enables stack lift.
    L.R. [↱] + [LN] ŷ, x̂, r, m, b ŷ and x̂ transform \(X\) into \(\hat{y}(X)\) or \(\hat{x}(X)\); r, m, and b push Pearson \(r\), slope \(m\), or intercept \(b\) to \(X\) observing stack lift.
    x?y [↰] + [÷] x=y, x≠y, x>y, x<y, x≥y, x≤y Compares \(X\) against \(Y\) (YES/NO banner interactively; evaluates to 1 when true and 0 when false inside EQN).
    x?0 [↱] + [÷] x=0, x≠0, x>0, x<0, x≥0, x≤0 Compares \(X\) against \(0\) (YES/NO banner interactively; evaluates to 1 when true and 0 when false inside EQN).
    POLY [↱] + [XEQ] A, B, C, D, CLR Unassigned slots default to 0; typing a value + tapping A–D stores (•) without STO/RCL; pressing [XEQ] solves cubic/quadratic (r1 \(\to Y, X\); all roots in REGS STO R1–R6 / R34–R39).
    TVM [↰] + [x∥y] N, I%, PV, PMT, FV, END/BEG Unassigned slots default to 0 (END default); typing or computing a value + tapping a softkey stores \(X\) (STO N, etc.); tapping immediately after another TVM softkey solves for that variable without STO, RCL, or XEQ.
    EQN [↱] + [STO] NEW, [1:Eq₁ … n:Eqₙ] Stores up to 24 RPN equations (A–Z); tapping an equation edits it, while [XEQ], [↱] [SOLVE], [↱] [∫], and CLEQN evaluate, solve, integrate, or clear equations.
    SOLVE [↱] + [7] [A], [B], ... \(\to\) SOLVE _ Selects stored equation and target variable (A–Z key or variable softkey; value + variable softkey stores parameter), prompts A?, B? (\(\to\) [ENTER]/[XEQ]) for unassigned parameters, seeds Brent's solver from \(x_0\) (default 0), and returns \(x^* \to X\).
    ∫ [↱] + [8] [A], [B], ... \(\to\) ∫ _ Integrates selected equation over \([a, b]\) in \((Y, X)\) with respect to selected variable (A–Z key or variable softkey), prompts A?, B? (\(\to\) [ENTER]/[XEQ]) for unassigned parameters, and returns \((\pm\varepsilon \to Y,\; I \to X)\).
    PLOT [↱] + [x∥y] [A], [B], ... (<, \|<-, OUT, IN, ->\|, >) Companion App feature (excluded from physical firmware for exam compliance): plots stored equation across \([\min(Y,X), \max(Y,X)]\) (default \([-3, 3]\), or \([-10, 10]\) via [XEQ]), or plots Σ+ scatter points when no equations are stored (CLEQN).
    REGS [↰] + [0] STACK, STO, STATS, DATA, ▲, ▼ Read-only inspector for stack (T,Z,Y,X,LASTX), variables/roots (A–Z, R1–R6 / R34–R39), statistical sums (R28–R33), and raw data (R40–R89).

    From any active softkey submenu, [C] (EXIT) dismisses the modal overlay and restores the six LFU telemetry slots along the bottom row without altering Register \(X\) or the current stack lift state.

    C.5 System Flags Directory (FLAGS Menu & Flags 0–9)

    The key sequence [↱] + [×] (FLAGS) opens the System Flags and Configuration workspace. On the StackCalc SC-32, ten persistent system and general-purpose flags (Flag 0 through Flag 9) govern instrument configuration, stack architecture, interface presentation, and rational fraction display formatting. Flags are modified interactively through the FLAGS toggle grid (pressing digits 0–9 directly on hardware/replica, or using SF 0–SF 9 and CF 0–CF 9 in the companion app):

    Flag # Engine ID Default State Access & Control Functional Role & Architectural Behavior
    Flag 0 0:F0 OFF (0) Digit 0 (SF 0 / CF 0) General-Purpose Flag 0: User-toggleable boolean flag 0 for status tracking.
    Flag 1 1:F1 OFF (0) Digit 1 (SF 1 / CF 1) General-Purpose Flag 1: Secondary user-toggleable boolean flag 1 for status tracking.
    Flag 2 2:INT HRD / APP Digit 2 or FLAGS \(\to\) UI Interface Presentation Mode: Selects between the hardware replica bezel layout (HRD/REPLICA, Flag 2 = ON) and the expanded touch interface (APP, Flag 2 = OFF) on companion software platforms.
    Flag 3 3:FACE Theme ID Digit 3 or FLAGS \(\to\) FACE Visual Faceplate Selector: Cycles the active visual faceplate palette (RETR, STLH, NOVA, SPAC, VOYG, SYNT, ARCD, BLCK) on companion software platforms without altering key coordinates or shift assignments.
    Flag 4 4:STK 4-LN (ON) Digit 4 or FLAGS \(\to\) STACK \(\to\) VIEW Stack Display Layout (4-LN vs. 1-LN): When set (4-LN), the LCD renders all four operational registers (\(T, Z, Y, X\)); when cleared (1-LN), the display focuses on active Register \(X\).
    Flag 5 5:DEP 4-LVL Digit 5 or FLAGS \(\to\) STACK (2-LVL, 4-LVL, 8-LVL, INF) Operational Stack Depth Selector: Selects classical 4-register RPN with \(T\)-replication (4-LVL), 2-register (2-LVL), 8-register (8-LVL), or dynamic 999-level LIFO heap (INF).
    Flag 6 6:MOD SC32 (OFF) Digit 6 or FLAGS \(\to\) MODE Instrument Architecture Profile: Cycles the active calculator model when inside the FLAGS menu (SC-32, SC-6, and domain models).
    Flag 7 7:FRC OFF (0) Digit 7 or [↰] + [.] (FDISP) Rational Fraction Display Mode (FDISP): Toggles Register \(X\) between floating-point decimal display (OFF) and rational mixed-fraction rendering \(a\,\frac{b}{c}\) (ON, with default ceiling \(c_{\max} = 4,095\)).
    Flag 8 8:/c OFF (0) Digit 8 or FLAGS \(\to\) MODE Factor vs. Best-Fit Denominator Mode (8:/c): When cleared (OFF, PRECISE), fractions use the best continued-fraction approximation with any denominator \(\le c_{\max}\); when set (ON, FACTORS), fractions round to /c (\(c_{\max}\)) and reduce by \(\gcd(n, c_{\max})\) so the denominator is a factor of /c.
    Flag 9 9:d/c OFF (0) Digit 9 or FLAGS \(\to\) MODE Fixed vs. Reduced Denominator Mode (9:d/c): When cleared (OFF), rational fractions reduce to lowest terms; when set (ON, FIXED), fractions retain the unreduced fixed denominator /c (\(c_{\max}\), e.g., 1 30/60).

    In addition to individual flag toggles (0–9, SF, CF), the FLAGS softkey menu provides the Sanctioned Examination Lockdown (EXAM) toggle. Invoking EXAM executes an atomic CLALL memory purge (zeroing the operational stack, LASTX, all 26 named variables A–Z, the indirect register i, statistical accumulators, and stored equations) and locks the instrument into a verifiable examination compliance state until exited.

    Within the symbolic Equation Bank ([↱] [EQN]) and interactive stack workflows, conditional piecewise branching is performed directly with the relational test menus [↰] [x?y] ([↰] + [÷]) and [↱] [x?0] ([↱] + [÷]). Interactively on the keypad, executing a relational test displays "YES" or "NO" on the status line; inside symbolic [↱] [EQN] expressions, each test evaluates to 1 when True and 0 when False. Multiplying two sub-expressions by complementary relational tests (such as X A x>y and X A x≤y) allows a single stored equation in [↱] [EQN] to switch cleanly between two physical regimes—such as Macaulay beam singularity brackets, subsonic vs. supersonic drag laws, or laminar vs. turbulent pipe friction—when evaluated via [XEQ], [↱] [SOLVE], or [↱] [∫].
