    Appendix A: Formal Stack-Lift State Machine

    The operational registers (\(X, Y, Z, T\)) of a Reverse Polish Notation (RPN) processor form a four-level last-in, first-out (LIFO) evaluation stack (Figure A.1), with \(X\) as the active bottom display register, \(Y\) as the second operative register, \(Z\) as the third, and \(T\) as the top constant register.

    On the SC-32, Register \(X\) is governed by a deterministic George H. Mealy (1955) finite-state automaton \((Q, \Sigma, \Delta, \delta, \lambda)\) called the Stack Lift Automaton—defined by a finite set of internal stack-lift states \(Q = \{\text{EDIT}, \text{ARMED}, \text{DISABLED}\}\), an input alphabet \(\Sigma\) of physical keystrokes, an output alphabet \(\Delta\) of register-transfer operations, a state-transition function \(\delta: Q \times \Sigma \to Q\) mapping the current state and keystroke to the next state, and an output function \(\lambda: Q \times \Sigma \to \Delta\) specifying the immediate register transformation—preserving the classical four-register state-transition rules of the HP-35, HP-15C, and HP-32SII (Hamblin, 1957; Cochran, 1972; HP, 1982; HP, 1991):

    • EDIT (Building a Number): Digit keys ([0]–[9], [.]) append to Register \(X\) without disturbing \(Y, Z,\) or \(T\).
    • ARMED (Lift = TRUE): Pressing any operator (such as [+], [×], [√x], [SIN], or [LN]) terminates digit entry, writes the result into \(X\), and arms lift. The next digit key pushes \(T \leftarrow Z, Z \leftarrow Y, Y \leftarrow X\) before starting a new number in \(X\).
    • DISABLED (Lift = FALSE): Set by [ENTER] (duplicates \(Y \leftarrow X\) and disarms lift), [<-] (CLx), [C], and [Σ+]/[↰] [Σ-]. Prefix keys ([↰], [↱], [E]) preserve Lift.

    A.3 Formal Register Delta Algebra & Configurable Stack Depth

    With the four-register operational state vector written as \(\mathbf{S} = [X, Y, Z, T]^T\) alongside the audit register \(\text{LASTX}\) and boolean stack-lift latch \(\mathcal{L}_{\text{lift}} \in \{\text{TRUE}, \text{FALSE}\}\), every unary operator \(f(X)\), dyadic operator \(g(Y, X)\), and stack-duplication keystroke [ENTER] executes one of three deterministic vector transitions (Eq. A.1)–(Eq. A.3):

    \[\mathbf{S}_{\text{unary}}' = \begin{bmatrix} f(X) \\ Y \\ Z \\ T \end{bmatrix}, \qquad \text{LASTX}' \leftarrow X, \qquad \mathcal{L}_{\text{lift}}' \leftarrow \text{TRUE} \tag{Eq. A.1}\]
    \[\mathbf{S}_{\text{dyadic}}' = \begin{bmatrix} g(Y, X) \\ Z \\ T \\ T \end{bmatrix}, \qquad \text{LASTX}' \leftarrow X, \qquad \mathcal{L}_{\text{lift}}' \leftarrow \text{TRUE} \tag{Eq. A.2}\]
    \[\mathbf{S}_{\text{ENTER}}' = \begin{bmatrix} X \\ X \\ Y \\ Z \end{bmatrix}, \qquad \text{LASTX}' \leftarrow \text{LASTX}, \qquad \mathcal{L}_{\text{lift}}' \leftarrow \text{FALSE} \tag{Eq. A.3}\]

    Each vector equation specifies the complete post-keystroke register state: * Unary In-Place Transformation (Eq. A.1): A single-operand function \(f(X)\) (such as [√x], [LN], [SIN], or [1/x]) overwrites Register \(X\) with \(f(X)\) while leaving the upper registers \(Y, Z,\) and \(T\) completely untouched, snapshots the pre-operation value of \(X\) into LASTX, and sets \(\mathcal{L}_{\text{lift}}' \leftarrow \text{TRUE}\) so the next number typed will lift \(f(X)\) into Register \(Y\). * Dyadic Collapse & Top-Register Replication (Eq. A.2): A two-operand binary operation \(g(Y, X)\) (such as [+], [-], [×], [÷], [yˣ], or [x∥y]) consumes \(Y\) and \(X\) to write \(g(Y, X)\) into Register \(X\), drops the upper stack downward by one level (\(Y' \leftarrow Z\) and \(Z' \leftarrow T\)) while retaining the top register (\(T' \leftarrow T\), enabling automatic constant replication across Horner polynomials and repeated scaling factors), saves the consumed \(X\) operand into LASTX, and sets \(\mathcal{L}_{\text{lift}}' \leftarrow \text{TRUE}\). * Explicit Stack Push & Lift Disarm (Eq. A.3): Pressing [ENTER] pushes the stack upward by one register (\(T' \leftarrow Z,\; Z' \leftarrow Y,\; Y' \leftarrow X\), discarding the old \(T\)) so that \(X\) is duplicated in both Registers \(X\) and \(Y\), leaves LASTX unchanged, and sets \(\mathcal{L}_{\text{lift}}' \leftarrow \text{FALSE}\) so that the next digit keystroke overwrites the temporary copy in Register \(X\) rather than lifting the stack a second time.

    Under [↱] [FLAGS] \(\to\) STACK (Flag 5), operational depth can be switched among four deterministic stack profiles:

    Stack Profile Active Registers Top-of-Stack Drop Rule Primary Engineering Use Case
    2-LVL \(X, Y\) Top-register replication (\(Y' \leftarrow Y\)) on dyadic drop Minimalist two-operand accumulator workflows
    4-LVL (Default) \(X, Y, Z, T\) \(Z' \leftarrow T,\; T' \leftarrow T\) (\(T\)-replication) Classical 4-register RPN, Horner evaluation, constant scaling
    8-LVL \(X, Y, Z, 4 \dots 7, T\) \(7' \leftarrow T,\; T' \leftarrow T\) (\(T\)-replication) Four-level complex phasor networks (CMPLX) and 8-register expressions
    INF \(X, Y, Z, 4 \dots 999\) (999-register dynamic stack) Dyadic drops pull zero-initialized upper levels (\(T' \leftarrow R_5\)) without duplicating \(T\) at level 4 Arbitrary-depth expression trees and multi-branch series

    For the Horner cubic \(P(x) = ((2x - 5)x + 3)x + 7\) at \(x = 3\), the four-register trace shows how [ENTER] (DISABLES lift, Eq. A.3) and dyadic operators (ENABLES lift with \(T\)-replication, Eq. A.2) cooperate across all four registers:

    Keystroke Register T Register Z Register Y Register X What Happens on the Stack
    3 [ENTER] [ENTER] [ENTER] 2 \(3\) \(3\) \(3\) \(2\) Fill stack with \(x = 3\); disabling lift after third ENTER lets 2 overwrite \(X\)
    [×] 5 [-] \(3\) \(3\) \(3\) \(1\) First Horner stage \(2(3) - 5 = 1\); \(T\)-replication preserves \(x = 3\) in \(Y, Z, T\)
    [×] 3 [+] \(3\) \(3\) \(3\) \(6\) Second Horner stage \(1(3) + 3 = 6\); \(x = 3\) remains staged in Register \(Y\)
    [×] 7 [+] \(3\) \(3\) \(3\) \(25\) Final cubic evaluation \(P(3) = 6(3) + 7 = 25\) with \(x = 3\) still in \(Y, Z, T\)
