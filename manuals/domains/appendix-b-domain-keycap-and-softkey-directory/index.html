    Appendix B: Domain Instrument Keycap & Workspace Directory

    This directory catalogs the physical keycaps, Row 0 contextual/LFU softkeys ([LFU0]–[LFU5]), yellow ([↰]) and blue ([↱]) shift layers, bidirectional Equation Solver Workspaces ([g] [SOLVE] / [XEQ]), and register input-output signatures across all nine instruments in the StackCalc Domain Series (SC-35 through SC-95, covered in Units I through IX, Chapters 1 through 27). Each table lists the pre-execution stack arguments consumed from Register T, Register Z, Register Y, and Register X alongside the post-execution results returned to Register X' and Register Y' and the softkey variable bindings inside each instrument's Equation Solver Workspace.

    Shared Three-Pillar Core Keys Across All Nine Instruments

    Every calculator in the StackCalc Domain Series is built on the same three-pillar architecture: configurable RPN stack depth (4-LV, 8-LV, or INF cycled on Flag 5 5:DEP inside [↱] [FLAGS]), dual-mode domain keys that combine one-key RPN stack evaluation with a bidirectional Equation Solver Workspace ([g] [SOLVE] / [XEQ] + [LFU0]–[LFU5]), and non-destructive Live Reference Ledgers ([g] [▦]) paired with ten general-purpose memory registers (R₀–R₉):

    Keycap / Sequence Function Name Pre-Execution Stack (\(Y, X\)) Post-Execution Stack (\(Y', X'\)) & Architecture Role
    [ENTER] Stack Lift & Duplicate Y, X X, X (prior \(Y \to Z\), \(Z \to T\); lifts across 4-LV, 8-LV, or INF via Flag 5 5:DEP in [↱] [FLAGS])
    [x⇄y] Swap Registers \(X\) and \(Y\) Y, X X, Y (\(Z\) and \(T\) unchanged)
    [R↓] / [↱] [R↑] Roll Stack Down / Up T, Z, Y, X X, T, Z, Y or Z, Y, X, T (cycles active stack window)
    [<-] / [C] Backspace / Clear \(X\) Y, X Y, 0.0000 (disables stack lift)
    [+/-] Change Sign / Negate Y, X Y, -X (or two's complement negation [f] [NEG] on SC-16)
    [STO] [0]–[9] Store \(X\) in Register \(R_n\) Y, X Y, X (\(R_n \leftarrow X\))
    [RCL] [0]–[9] Recall Register \(R_n\) to \(X\) Y, X X, Rₙ (lifts stack first)
    [g] [SOLVE] / [XEQ] Bidirectional Solver Arm Y, X Arms Equation Workspace to solve forward or backward for the next [LFU0]–[LFU5] softkey pressed
    [LFU0]–[LFU5] Row 0 Softkeys (Cols 0–5) Y, X Populates dynamically with recently/frequently used operations (LFU) when idle, or stores/solves symbolic variables in an active Equation Workspace
    [g] [▦] Live Reference Ledger Y, X Opens non-destructive domain reference lookup and ledger (@COGO, @BOM, @BK%, @PAT, cash-flow / stats table)
    [↰] Yellow Primary Shift — Arms yellow shifted legend for next key
    [↱] Blue Secondary Shift — Arms blue shifted legend for next key
    [↱] [SHOW] Full-Precision Mantissa Peek Y, X Temporarily reveals all 15–17 significant IEEE 754 digits of \(X\)
