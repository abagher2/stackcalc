    FRAC-01 // FULL-SCREEN CLASSROOM SIMULATOR

    Fraction Towers & Proportional Equivalence Studio

    FRACTION PALETTE:
    1. REGISTER X (ENTRY)
    0
    2. REGISTER Y (STACK)
    Y: 0 (0.0 mm)
    ACTIVE VALUE IN REGISTER X: Height: 0.0 mm • Val: 0.000
    STACKCALC // RPN ENGINE [↰ FDISP: ON]
    T: 0.0000
    Z: 0.0000
    Y: 0.0000
    X: 0_
    RPN STACK MECHANICS:
    • Register X (Left): Active entry tower. Tap chips to stack.
    • [ENTER]: Pushes X into Register Y (Right).
    • [+] [−] [×] [÷]: Compute Y and X on the stack.
    • Stack Lift: Entering a new block after calculation automatically lifts X to Y!
